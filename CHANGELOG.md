# Changelog

## 0.2.0 — 2026-10-22

- Establish FieldGuide as a GPL-2.0-only Python package with tests, CI and versioned wiki documentation.
- Retain original local document retrieval, optional local RAG, inventory, notes and backups.
- Add raster MBTiles viewing and portable waypoints.
- Add explicitly selected, token-gated local peer bundles with checksum verification and idempotent imports.
- Add an experimental short-message FSK WAV encoder/decoder with ultrasonic and audible profiles.
- Keep native Android radios/APK, Bluetooth, vector maps, live acoustic capture and hardware validation marked as pending.
