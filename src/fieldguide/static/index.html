Export documents, metadata, inventory and notes as JSON. Models, external content files and chat responses are not included.

Merge a backup

Documents are deduplicated. Inventory and notes are appended, so importing the same backup repeatedly duplicates those entries. For an exact recovery, restore into a fresh database.
